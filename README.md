# Sınav Çalışma Notları

2021-22, 2022-23, 2023-24 ve 2024-25 final sınavları analiz edilerek hazırlanmış çalışma notları.

## İçerik

| Ders | Soru sayısı | Birebir tekrar |
|---|---|---|
| Fizyoloji | ~50/sınav | ~10 soru |
| Anatomi | ~32/sınav | ~13 soru |
| Farmakoloji | ~10/sınav | ~5 soru |
| Patoloji | ~8/sınav | ~2 soru |

## GitHub Pages'te Yayınlama

1. Bu repoyu GitHub'a yükle
2. Repo ayarları → Pages → Branch: `main`, Folder: `/ (root)` seç
3. Kaydet → birkaç dakika bekle
4. `https://KULLANICIADIN.github.io/REPOADI` adresinden eriş
